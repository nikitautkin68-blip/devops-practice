# Сайт-портфолио

Эта папка содержит локальную версию сайта. Команда запуска привязывает сервер только к `127.0.0.1` (этому компьютеру): сайт не будет доступен другим устройствам в сети. GitHub Pages не настраивается, сайт сам по себе ничего не публикует в интернет.

## Запуск на macOS или Linux

1. Откройте терминал в корневой папке репозитория `devops-practice`.
2. Запустите локальный веб-сервер:

   ```sh
   python3 -m http.server 8000 --bind 127.0.0.1 --directory www
   ```

3. Откройте в браузере <http://localhost:8000>.
4. Чтобы остановить сервер, вернитесь в терминал и нажмите `Ctrl+C`.

## Запуск на Windows

Откройте PowerShell в корневой папке репозитория и выполните:

```powershell
py -m http.server 8000 --bind 127.0.0.1 --directory www
```

Затем откройте <http://localhost:8000>. Если команда `py` не найдена, установите Python 3 и повторите запуск через `python -m http.server 8000 --bind 127.0.0.1 --directory www`.

## Запуск из VS Code

Можно установить расширение **Live Server**, открыть `www/index.html`, нажать правой кнопкой мыши и выбрать **Open with Live Server**. VS Code откроет локальный адрес в браузере. Для простого просмотра расширение устанавливать не обязательно — достаточно команды выше.

## Где редактировать сайт

- `index.html` — тексты, заголовки, проекты и контакты.
- `css/styles.css` — оформление и адаптивная вёрстка.
- `js/main.js` — переключение темы, мобильное меню и анимация терминала.

После изменения HTML, CSS или JavaScript обновите страницу в браузере. Если меняете личные контакты или описание навыков, проверьте, что хотите показывать эти данные другим людям, прежде чем делиться папкой или репозиторием.

## Если сайт не открывается

- Убедитесь, что команда сервера ещё работает в терминале.
- Если порт `8000` занят, используйте `8001` и откройте <http://localhost:8001>: `python3 -m http.server 8001 --bind 127.0.0.1 --directory www`.
- Открывайте сайт через `http://localhost:8000`, а не двойным щелчком по HTML-файлу: локальный сервер обеспечивает корректную работу JavaScript и ресурсов.
